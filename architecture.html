Global Filter System

All four filters are managed by composables/useFilters.js and applied globally. Each view watches filter state and re-fetches via src/api.js. The backend receives filters as URL query params and applies them to in-memory data.

transactions.json Individual line-item transactions — date, description, amount, category, vendor

Key Design Patterns

Reactivity Model

  • Raw API data stored in ref()
  • Derived/display values in computed()
  • Filters in shared composable
  • watch() triggers re-fetch on filter change

Composables

  • useFilters.js — global filter state
  • useAuth.js — authentication state
  • useI18n.js — i18n / locale
  • Shared singletons across all views

Backend Filtering

  • apply_filters() — warehouse, category, status
  • filter_by_month() — month or quarter
  • Filters run on in-memory Python lists
  • Original data never mutated
